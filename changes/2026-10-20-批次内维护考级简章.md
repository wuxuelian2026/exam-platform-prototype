# 批次内维护考级简章

- 日期：2026-10-20
- 分支：`v1.120261019需求变更`
- 原型事实源：`current/admin/index.html`
- 目标：取消机构独立简章入口，统一由批次引用平台已发布简章并维护批次专用内容。

## 菜单及来源

1. 移除后台“机构考级简章”“考级简章审核”菜单，平台、承办单位、培训机构均不再展示；旧地址转到“平台考级简章”，保留历史数据但不再进入原页面。
2. 平台考级简章的发布管理保留；不改变各角色原有批次新增、审核、发布权限，不新增培训机构创建批次的权限。
3. 新建批次的关联简章从当前平台简章数据动态读取，仅包含平台已发布的可用版本；机构已发布、未发布、待审核及历史归档简章不进入选项。
4. 无可用平台简章时展示空状态，保存、提交审核、发布均阻断；校验使用来源 ID 和真实状态，不依赖页面“已发布”文字。

## 批次内编辑规则

- 在基础信息后新增“考级简章”页签，线上、线下批次均展示。
- 选择后带入标题、14 个正文板块、附件、来源单位及版本。

| 内容 | 批次内权限 |
| --- | --- |
| 考级对象、教材与级别、评审标准、证书奖励、成绩公布 | 只读；平台操作批次时也不得改写 |
| 报名手续、费用、考试时间地点、开考科目、联系地址、报名时间、考试方式、退费与改报、其他说明 | 可编辑 |
| 简章标题 | 可编辑，必填，最多100字 |
| 附件 | 带入、添加、移除；PDF、Word、JPG/JPEG/PNG，单文件不超过20MB |

- 只读板块保存时沿用所选版本快照，忽略输入框被篡改后的值。
- 更换简章会重新带入新版本内容；当前内容或附件已有修改时先确认，取消则恢复原选项并保留编辑内容。
- 切换普通页签、考试方式或重复选择同一来源，不覆盖已编辑内容。
- 草稿可暂缺正文内容，提交审核和发布必须补齐14个正文板块。
- 正文中的费用、时间和开考科目为简章说明文字，不反向改写批次的结构化时间、执行专业及收费配置。

## 保存及历史

- 批次保存独立的 `brochureSnapshot`，包含来源 ID/版本/标题/单位、本批次简章标题、正文及附件；保留 `brochureId`、`brochureVersionId` 和 `brochureName` 供原列表和关联使用。
- 编辑批次按来源 ID 回显，标题修改不影响来源识别；批次列表的简章查看展示本批次保存后的内容。
- 不回写平台原简章，不影响其他批次；平台后续修改内容不覆盖已保存的批次快照。
- 来源已不可选时不自动换成另一份简章，历史内容仍保留用于查看，继续保存前需重新选择平台已发布简章。
- 附件交互沿用前端原型演示口径，只记录文件名称，不上传真实服务器；批次数据沿用现有演示生命周期。

## 验收

- 新增11项自动化检查，覆盖菜单/角色访问、动态来源、五项只读、独立快照、保存回显、换源确认、附件限制及历史来源失效。
- 全量41项自动化测试通过；浏览器验证带入、只读、可编辑内容保存及重新编辑回显通过，旧机构简章地址已转向平台简章。
