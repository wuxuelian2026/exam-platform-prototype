# 培训活动表单与视频上传

日期：2026-10-20
分支：`v1.120261019需求变更`
范围：管理端「师资培训 → 培训活动发布 → 新增培训活动」。

## 表单

按客户截图调整字段和顺序，普通字段两列、地点和媒体及说明整行。

| 字段 | 规则 |
| --- | --- |
| 活动编号 | 只读，首次保存时自动生成；续编草稿保留编号 |
| 活动名称 | 必填，最多100字 |
| 培训方向 | 发布必填，最多50字 |
| 培训方式 | 只读，固定线下培训 |
| 报名日期 | 发布必填，开始日期至截止日期 |
| 培训日期 | 发布必填，开始日期至结束日期 |
| 人数上限 | 发布必填，1至100000的整数 |
| 培训费用（元） | 发布必填，支持0元，最多两位小数，上限999999.99 |
| 培训地点 | 发布必填，最多200字 |
| 活动封面 | 选填，JPEG/PNG，不超过2MB，支持预览、替换、移除 |
| 视频上传 | 选填，暂按MP4、不超过100MB实现，支持播放预览、替换、移除 |
| 活动说明 | 选填，最多5000字 |

去掉原新增表单中的培训对象、联系人、联系电话，不再作为发布校验项。
开始日期不能晚于对应结束日期；报名截止不能晚于培训开始。

## 操作与保存

- 底部为「关闭、保存草稿、保存并发布」。
- 保存草稿至少填写活动名称；其他已填写字段仍校验格式与范围。
- 新建草稿在列表显示草稿、未开始；可编辑、刷新后续编、发布，保持同一编号且不重复生成记录。
- 发布校验全部必填项；详情展示所填字段、封面、视频及说明。
- 活动元数据使用localStorage，媒体文件使用IndexedDB，避免将大视频写入localStorage。
- 文件格式/体积错误或存储失败时明确提示，不误报成功；重复提交在保存期间拦截。
- 仍仅平台账号可新增或保存培训活动，不变更其他角色的菜单权限。

## 验证

- 自动化覆盖字段、日期、费用与人数、草稿续编、发布、角色限制、媒体格式/体积、存储失败和转义。
- 浏览器验证新增表单、封面上传、草稿刷新回显、续编发布、详情展示及非MP4拦截。
- 仅前端原型，文件保存在当前浏览器和当前站点，不接入真实上传服务；正式实现需后端文件存储。
- 视频格式和100MB上限为原型默认值，客户尚未指定，可后续调整。
